# v0.1.0 发布范围与验证

本次发布为地形版：PC/Web 与移动/PWA 共仓库，MIT 许可；历史入口为《坤舆纪年》原站外链，不包含原项目历史实现和数据。

## 来源与边界

PC/Web 代码来自现有在线静态页面快照，移动代码来自 Sites 源码。未迁移先前开发历史，也未宣称已核验 PC 原始源码仓库。本次 GitHub 发布不更新现有 Vercel 或 Sites 部署。

## 验证

- JavaScript 语法检查（含 PC 页面内联脚本）。
- 常见凭据模式扫描；不包含 `.env`、私有仓库凭据、Sites 托管身份文件或旧开发提交。
- 历史加载、几何解码和图层实现已从发布目录移除。
- 修正后的 geoBoundaries 资源经解析为 FeatureCollection，共 2391 个要素。
- Chromium：PC 1440×1000 与移动 390×844 均初始化地图画布；25× 高程控制、地球仪/平面切换和历史外链可用；无页面脚本错误、无历史上游网络请求。
- 浏览器测试使用环境出站代理，并为代理证书设置测试专用 ignoreHTTPSErrors；应用代码没有禁用 TLS 验证。

外部地图服务需要联网；测试环境经出站代理访问。外部瓦片完整覆盖、所有设备 PWA 安装和离线地图不在本次验证保证范围内。
